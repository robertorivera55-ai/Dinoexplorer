# 🦖 Dino-Explorer
**Proyecto Final de Programación Orientada a Objetos - UABC**

Este es un videojuego educativo interactivo donde los usuarios exploran fichas técnicas de dinosaurios.

## 📁 Estructura del Proyecto
* `/src`: Código fuente organizado en capas (Lógica y UI).
* `/assets`: Recursos gráficos y multimedia.
* `/docs`: Reporte final y documentación.
